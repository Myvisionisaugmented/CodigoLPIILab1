# Evaluación: Procesador de Datos de Google Drive y Python

Módulo en Python diseñado para interactuar con Google Drive, filtrar archivos (.json y .csv), extraer metadatos, validar el esquema del archivo `inventario.json` y retornar la información estructurada en un diccionario.

## Características
- Filtrado de archivos por extensión.
- Extracción de metadatos (tamaño y fecha).
- Validación de estructuras de datos (listas de registros).
- Retorno estructurado para consumo de APIs.
